## 方針（2026-10-06 決定）

- **家族向けに iPhone アプリとして TestFlight で配る。収益化はしない**（自分と家族が使いやすいアプリを作るのが目的）
- 費用は Apple Developer Program（年 99 ドル）だけにする
  - Web 版は GitHub Pages のまま（無料）。アプリ版は画面のファイルをアプリに同梱するので Web サーバー不要
  - DB は今の Firebase（1 プロジェクト）の無料枠のまま
  - 通知のために Firebase を Blaze に切り替えるが、無料枠内で使う（予算アラートを低めに設定、送りすぎの上限を入れる）
- 「各自で Firebase を用意してもらう」方式はやらない（準備が難しすぎ、審査の助けにもならない）
- 一般公開・収益化は、家族で使ってみて「人に勧められる」と思えたら改めて考える
