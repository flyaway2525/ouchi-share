## 方針

- **2026-10-10：有料で App Store に出す方向に変えた**。アプリは 1 本で、無料・👑 サブスク・💎 買い切りの 3 段。グループのみんなで使うのはサブスクの特典（docs/design.md の「有料プランの方針」、出すときの下書きは [app-store.md](app-store.md)）

- 費用は Apple Developer Program（年 99 ドル）だけにする
  - Web 版は GitHub Pages のまま（無料）。アプリ版は画面のファイルをアプリに同梱するので Web サーバー不要
  - DB は今の Firebase（1 プロジェクト）の無料枠（Spark）のまま。通知は Cloudflare Workers の無料プランで送る（下の 5.）
- 「各自で Firebase を用意してもらう」方式はやらない（準備が難しすぎ、審査の助けにもならない）
