# 実機確認リスト

PC の Chrome では確かめたが、実機ではまだ確かめていないもの。実機で確かめたら、結果の欄に ✅（OK）・❌（ダメ。下の「わかったこと」に様子を書く）・—（関係なし）を書く。
環境によって動きが違ったら、その環境に合わせて直す（CLAUDE.md の「対応する環境」）。

アプリの形は 3 つ（CLAUDE.md の「対応する環境」）。表の列は「形 × 端末」：

| 列 | 形 | 端末 |
|---|---|---|
| **iS** | ブラウザ版 | iPhone（Safari） |
| **iH** | ホーム画面版 | iPhone |
| **iA** | アプリ版 | iPhone（TestFlight） |
| **AC** | ブラウザ版 | Android（Chrome） |
| **AH** | ホーム画面版 | Android |

PC のブラウザ版は、手元の Chrome で確かめている（Android のアプリ版は、作ったら列を足す）。

## わかったこと
- v118：iPhone アプリ版（iA）で Google ログインが「window.Capacitor.registerPlugin is not a function」で失敗 → ビルドなしで @capacitor/core を読み込んでいないため。`Capacitor.nativePromise` で直接呼ぶ形に直して、ログインできた（2026-10-09、iPhone 16 Pro・iOS 26.6.1）
- v87〜v89：iPhone で＋の短押しから登録できないと報告あり（どの段階で止まるかはまだ不明。v89 で「すぐ登録の画面を出す」形に変えたので、もう一度確かめる）
- v85：iPhone でリストの並べ替えのあとカレンダーのタブに切り替わる件は、まだ直っていない
