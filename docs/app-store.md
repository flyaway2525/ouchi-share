## 説明文（4,000 文字まで）

```
家族や友だちの小さなグループで、予定・やること・思い出をひとつの場所で共有できるアプリです。

■ カレンダー
・家族みんなの予定を 1 つのカレンダーで。人ごとの色で、誰の予定かひと目でわかります
・誕生日や記念日は「記念日カレンダー」で、○歳・○周年・あと○日まで表示
・祝日・土日の色分け、テキストでまとめて予定を書ける「テキスト予定表」

■ イベント・旅程
・旅行などの期間のある予定に、日ごとの行程と持ち物リスト

■ リスト
・買い物・持ち物・やることを、チェックしながら共有
・行きたいところ・欲しいものは、リンクを貼るだけでタイトルと画像を登録

■ 日記
・家族の出来事を、日時・メンバー・タグつきで残せます

■ ログインボーナスとごほうび
・毎日開くとチケットがもらえて、家族で決めたごほうびと交換（承認制）
・予定に報酬をつけて、子どものお手伝いや習い事のやる気アップにも

■ 着せ替え・壁紙
・色・フォント・アイコン・演出・壁紙がセットになった着せ替え
・タブを移ると奥行きのある動きをする壁紙

■ かんたんに始められる
・招待リンクを送るだけ。アカウントを作らずに、ゲストとしても参加できます
・通知で、予定の追加やお知らせをお知らせ

【有料プランについて】
・おうちでシェア サブスク（月額・年額）：公式の着せ替えが使い放題、自分の写真の壁紙、壁紙のおすそわけ。サブスクの方がいるグループでは、メンバー全員が公式の着せ替えを使えます
・お支払いは Apple ID に請求されます。サブスクは、期間が終わる 24 時間前までに解約しない限り自動で更新されます。解約は、端末の「設定」→ Apple ID →「サブスクリプション」から行えます

利用規約：https://flyaway2525.github.io/ouchi-share/terms.html
プライバシーポリシー：https://flyaway2525.github.io/ouchi-share/privacy.html
```

## App のプライバシー（App Store Connect の質問への答え）

「データを収集していますか？」→ はい。どれも**トラッキングには使わない**（ほかの会社のデータと組み合わせない・広告に使わない）。

| データの種類 | 集めるもの | 使う目的 | ユーザーに紐づくか |
|---|---|---|---|
| 連絡先情報 > 名前 | ニックネーム・表示名 | アプリの機能 | はい |
| ユーザーコンテンツ > 写真またはビデオ | アイコンの写真・リンクの画像 | アプリの機能 | はい |
| ユーザーコンテンツ > その他のユーザーコンテンツ | 予定・リスト・日記・お知らせ | アプリの機能 | はい |
| 識別子 > ユーザー ID | ログインのアカウントの ID | アプリの機能 | はい |
| 識別子 > デバイス ID | 通知の送り先の ID | アプリの機能 | はい |
| 使用状況データ > 製品の操作 | 開いた画面の種類（GA4。アプリ版に入れたとき） | 分析 | いいえ |

- 壁紙の写真・動画は端末の中だけ（おすそわけのときだけ 7 日間サーバーに置く）→「ユーザーコンテンツ」に含めて答える
- アプリ版に GA4 を入れる前なら、「使用状況データ」の行はなし（todo.md の「アクセスの計測をアプリ版にも」）
